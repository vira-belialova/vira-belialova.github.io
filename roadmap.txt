🔴 Этап 1 — Access / безопасность

1. Скрытие protected content до проверки

 Проверить CSS/HTML: protected-контент изначально display:none
 Проверить valid token → контент раскрывается
 Проверить invalid token → контент остаётся скрытым
 Проверить отсутствие token → публичная страница работает

2. Очистка token из URL

 После успешной проверки убрать ?access=TOKEN
 Проверить, что доступ после этого не ломается
 Проверить reload

3. Повторное использование token

 Проверить старый token
 Проверить новый token
 Определиться: token одноразовый или постоянный
 При необходимости добавить invalidation на Supabase

4. Ошибки backend

 invalid token
 Supabase 500
 network error
 timeout
 Понятное состояние UI для каждого сценария
